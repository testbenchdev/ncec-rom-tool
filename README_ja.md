# NCEC ROM Tool

**マツダ ロードスター NC（型式 NCEC、LF-VE エンジン、Denso 279700-4073 / Renesas SH7058、CAL ID LFG7EG）**
の純正ECUを、**読み出し・編集・照合・書き込み・ライブ計測**するためのオープンソースツールです。
純正ECUのまま LinkECU / Haltech 風のチューニング環境を目指す、趣味・学習目的のプロジェクトです。

現在のバージョン: **2.30**（`VERSION`。変更履歴は `CHANGELOG_ja.md`）
English: [README.md](README.md)

### 書き込みについて
このECUへの書き込みには、NC1用の **SBL（セカンダリ・ブートローダ）**（書き込み開始 0x2000、0x1800バイト）が必要です。
認証と書き込みシーケンス（`10 85` → `27` → `B1 00 B2 00` → RequestDownload 0x8000/0xFF800 → SBL＋プログラム →
TransferExit → リセット）、チェックサム処理、ブロック長は実装済みで、実機で確認済みです。
**本プロジェクトはSBLを配布しません。** エディタの **［ECU書き込み］** は既定で
`Decryption_sbl/sbl_nc1_flash_0x2000.bin` を読みます。コマンドラインは `tools/flash_writeback.py`
（`--confirm` を付けない限りドライラン）です。

### フラットシフト（ノーリフトシフト）
- 純正のクラッチ連動スロットルカット（`@0x0C53BC`、6500rpm）は、**車速2km/h未満**（`@0x0C53B8`）のときしか効きません。
  停車中の空ぶかし／ローンチ用リミッタとしては働きますが、走行中のフラットシフトには**なりません**。
  （v1.10の説明は誤りで、v1.20で訂正しました。）
- **点火リタード・パッチ**（`ncecu/flatshift.py`、第3ドラフト）は、クラッチ踏込 かつ アクセル開度>しきい値 かつ
  回転>しきい値 かつ 車速>下限 の間だけ、最終進角からリタード量を引きます。引くのは純正の最大リタード・クランプの前です。
  走行中はスロットルを開けたままにできます。既定値は 80% / 7000rpm / 10km/h / 20°。
- エディタの **［フラットシフト］** ボタン、または `tools/patch_flatshift_retard.py` で適用します。適用後は、ツリーの
  **『パッチ - フラットシフト（点火リタード）』** に4項目が表示され、値を編集できます（範囲外の入力は拒否）。
  詳細は `docs/tuning_flatshift_ja.md`。
- 点火制御を変更するパッチで、排気温度も上がります。**まずベンチECUで確認してください**
  （タイミングライト、またはライブ計測の点火時期 PID 0x0E）。

## 動作環境

- Python 3.11 以上（開発は 3.14 / Windows 11）
- CANアダプタ: **gs_usb 系（candleLight。例: DSD TECH SH-C30L）**、500kbps。Zadig で WinUSB ドライバを割り当て
- 依存パッケージ: `pip install -r requirements.txt`
- GUIは Python 標準の tkinter を使用

### ROM定義（マップ定義）
マップ定義には **LibreTuner の `mx5_nc` 定義（作者 speepsio）** を使います。ライセンスを明確にするため
**同梱していません**。以下から入手し、`main.json` と自分のCAL IDの `<CALID>.json`（例: `LFG7EG.json`）を
`defs/libretuner/` に置いてください。
- https://github.com/LibreTuner/LibreTuner（`ui/resources/definitions/mx5_nc/`）

この定義に無い一部の定数（上記フラットシフト関連）は `ncecu/flatshift.py` で定義しており、エディタが追加項目として表示します。

## インストール

```bash
git clone https://github.com/testbenchdev/ncec-rom-tool.git
cd ncec-rom-tool
pip install -r requirements.txt
# LibreTuner の mx5_nc 定義を defs/libretuner/ に置く（上記参照）
python ncec_editor.py
```

## 使い方（概要）

1. **［ROMを開く］** — 吸い出したダンプ（`.bin`、1MB）を読み込む。
2. 左のツリーでマップを選び、セルを編集（Enterで確定）。保存時にチェックサムを自動補正。
3. **［Live ▶］** — 動作中のECU（OBD-II / CAN）に接続してライブ計測。変化のゆっくりしたPIDは間隔を空けて
   問い合わせ（`ncecu/livelog.py` の `DEFAULT_PID_INTERVALS`）、速いPID（回転数など）の更新を速くします。**［ダッシュボード］** でゲージ表示、
   **［記録 ●］** / **［リプレイ］** でログの記録と再生。
4. **［ECU吸出し］** でECUをダンプ。**［ECUと照合］** / **［ROM照合］** で差分を確認。
5. **［ECU書き込み］** で書き込み（予備/ベンチECU推奨。SBLが必要）。
6. **［フラットシフト］** で点火リタード・パッチ（ドラフト）、**［アンチラグ］** で減速ポップ（A/B/C選択）、**［電スロチューニング］** で電子スロットル1:1化を、開いているROMに適用（いずれも変更したmapをリザルト表示）。
7. 言語ボタンで **日本語 / EN** を切替。**［ヘルプ］** で `docs/editor_help_ja.md` を表示。
8. `python tools/gen_manual.py` で全マップのPDFマニュアルを生成。
