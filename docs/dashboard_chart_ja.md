# ダッシュボード表示モードとログ分析チャート

ライブ計測の表示を強化しました（別プロジェクト OBD2monitor の表示方式を反映）。

## 1. 更新の体感速度（なめらか表示）

- ライブ表示のUI更新を **約20Hz**（従来150ms→50ms）に引き上げ、数値・マップの赤●がポーリング周波数に追従するようにしました。
- ダッシュボードは**独立した約30fpsの描画ループ**を持ち、「なめらか」設定の項目は**直近2値を線形補間**して針/バーが滑らかに動きます（グラフモードは生データのまま）。
  - ⚠ なめらか表示はわずかに表示が遅延します。即時性重視なら右クリック→「更新: なめらか」をオフに。
- 補足：**間引き（設定→ライブPID間引き）**で遅く設定した項目は、その間隔でしか更新されません（回転数など「毎回」の項目は高速）。

## 2. ダッシュボードの表示モード

タイルを**右クリック**して選べます。
- **数値** … 大きな数字（従来）。
- **棒（バーメーター）** … 現在値を棒の長さで。下限〜上限の範囲に対する割合。**縦・横どちらでも**表示可能（下記）。
- **メーター** … アナログ風ゲージ（針＋目盛り＋中央数値）。針は細く、中央数値・項目名は小さめにして目盛りが読みやすい配置（v2.00）。
- **グラフ** … 時系列（既定12秒・**横軸の時間は調整可**）。アラーム線つき、横軸に時間ラベル。

### メータのはみ出し対策（v1.90）
アナログメータ（270°・下開き）は、タイルの幅・高さから収まる半径を自動計算して**枠や見出し・隣のタイルにはみ出さない**ようにしました。目盛りとレンジ数値はメータの内側、現在値は開口部の内側、回転数の `×1000` 表記は左下に配置します。

### アラーム値の赤表示（v1.90）
「アラーム値を設定…」で決めた値を、**赤帯（レッドゾーン）**として常時表示します。
- **メーター**：アラーム値から上限まで（KRなど下限アラームは下限側）を赤い円弧で表示。
- **棒**：アラーム側を赤帯＋赤ラインで表示。
- 現在値がアラームを超えると、**針・数値・タイル枠が赤**に変わります（従来のタイル点滅に加えて）。

### 棒グラフの縦／横（v1.90）
棒モードのタイルを右クリック→**「棒の向き」**で **縦（下→上）／横（左→右）** を選べます。指定しない場合はタイル形状で自動（縦長→縦、横長→横）。縦横どちらも目盛り＋レンジ数値、アラーム赤帯付きです。

### 表示色の変更（v2.00）
右クリック→**「表示色…」**で、そのタイルの表示色（針・バー・グラフ線・数値）をカラーピッカーで自由に変更できます。項目ごとに色分けして一目で区別できます。アラーム値を超えた時は従来どおり赤に変わります。

### スケール（表示範囲・目盛り間隔）の調整（v2.00）
右クリック→**「スケール(範囲・目盛り間隔)…」**で、下限・上限に加えて**目盛り間隔**を指定できます（空欄=自動で4分割）。メーター・棒・グラフの目盛りに反映されます（例：回転数を1000刻み、AFRを1刻み）。目盛りが過密にならないよう最大40分割にクランプします。

### グラフ横軸（時間幅）の調整（v2.00）
グラフモードのタイルを右クリック→**「横軸の時間…」**で、時系列の表示時間を **1〜600秒** で設定できます。横軸には時間ラベル（例 −6s／−3s／0）が表示されます。

右クリックメニューではほかに、
- **更新: なめらか** のオン/オフ、
- **更新周期**（v1.90）…この項目の問い合わせ間隔を **毎回／0.5／1／2／5／10秒** から選択。ライブ計測のPID間引き（`live_pid_overrides` / `live_intervals.json`）とライブRAMの `interval`（`ram_reads.json`）へ即時反映し、動作中のライブ計測にも適用。設定中の周期はタイル見出しに `[2s]` のように表示されます。
- **アラーム値を設定…**（上限。KRは下限。超えるとタイルが赤く点滅）、
- 項目の削除。

設定（位置・サイズ・モード・棒の向き・範囲・**目盛り間隔・表示色・グラフ横軸時間**・アラーム）は `dashboard_layout.json` に保存され、次回も復元されます。KR/クラッチ/排気温（Mode23ライブRAM）もタイルにできます。

## 3. ログ分析チャート（設定 → ログ分析チャート…）

記録した `logs/livelog_*.jsonl` を、**複数チャンネルを縦に並べた時系列グラフ**として開き、共通の時間軸で相関を見られます（例：回転数・点火時期・AFR・KR を並べて、ノック時に点火が引かれKRが深くなる様子を確認）。

- 左の一覧でチャンネルの表示/非表示を切り替え。
- **マウスを重ねると縦カーソル**が出て、各チャンネルのその時刻の値を右端に表示。
- **ホイールでズーム**（カーソル中心）、**ドラッグで横スクロール**、**[全体]** で全域表示。
- 縦軸は項目ごとに既定レンジ（無い項目は自動スケール）。
