## 1. メモリマップ（内蔵ROM有効モード／シングルチップ）  (p184)

| アドレス | 内容 | サイズ |
|---|---|---|
| `0x0000_0000`–`0x000F_FFFF` | 内蔵フラッシュROM | 1MB |
| `0x0010_0000`–`0x001F_FFFF` | 予約 | |
| `0x0020_0000`–`0x00FF_FFFF` | CS0〜CS3 外部空間（ECUでは未使用の可能性大） | |
| `0xFFFF_0000`–`0xFFFF_BFFF` | 内蔵RAM | 48KB |
| `0xFFFF_C000`–`0xFFFF_FFFF` | 内蔵周辺モジュールのレジスタ | 16KB |

- ROMダンプは `0x00000`–`0xFFFFF` の 1MB（1,048,576 バイト）が完全なイメージ。
- ライブデータ（回転数・補正値など）は RAM `0xFFFF0000`〜 上にある。将来のロガー／RAMチューニングで使うアドレス帯。

## 2. フラッシュのブロック構成（消去単位）  (p699 図24.4)

| ブロック | アドレス範囲 | サイズ |
|---|---|---|
| EB0–EB7 | `0x00000`–`0x07FFF`（4KB×8） | 32KB |
| EB8 | `0x08000`–`0x1FFFF` | 96KB |
| EB9–EB15 | `0x20000`–`0xFFFFF`（128KB×7） | 896KB |

- 消去はブロック単位。マップ（キャリブレーション）が載っているブロックだけを書き換えれば、書き込み時間と書き換え回数を節約できる。
- ハード機能の「RAMエミュレーション」は EB0–EB7（4KB ブロック）のみ対象。

## 3. フラッシュの電気的特性  (p903)

- **書き換え保証回数: 最小 100 回**（NWEC）。
- 書き込み: typ 1ms / 128バイト、消去: typ 1.3s / 128KBブロック。全面書き換えは typ 20s、最大 50s 程度。
- 書き込み／消去時の周囲温度条件は -40〜85°C。

→ **GUIツールの設計方針への影響**:
  - 「マップを1つ直すたびに全面フラッシュ」は避ける。変更のあったブロックだけを書く差分書き込みを基本にする。
  - 実際のセッティング作業はオフライン編集＋まとめて書き込みを基本にし、書き込み回数をツール側で記録・表示する。

## 4. 動作モード  (p131 表4.1)

FWE / MD2–MD0 端子の組み合わせで決まる。ECU通常動作は「MCUシングルチップモード」。
フラッシュ書き換え用に以下のモードがある。

- **ユーザプログラムモード**: FWE=1 で通常起動。動作中のプログラム（ECU自身のファームウェア）がフラッシュを書き換える。CAN経由の書き換えは通常この仕組みで行われる。
- **ブートモード**: MCU内蔵のブートプログラムが起動し、**SCI1（非同期シリアル、9600 / 19200bps）** 経由でホストから書き込む。
- **ユーザブートモード**: ユーザブートマット（無印SH7058は 8KB、SH7058S は 12KB）のプログラムから起動。
- ライタモード: 専用ライタ用。

### ブートモードの重要な性質  (p718–p720)

- ブートモードに入って書き込み状態に移ると、**ユーザマットとユーザブートマットが全消去される**。
  - つまり、ブートモードは**純正ROMの読み出しには使えない**（読めるのは消去後に書き込んだデータだけ）。
- 一方で、CAN経由の書き込みに失敗してECUが起動しなくなった場合の**復旧手段**になる。
  - 条件: 基板上で FWE / MD 端子と SCI1（TxD1/RxD1）にアクセスすること、事前に取得した**完全な1MBのバックアップ**があること。
  - 予備ECUで作業する今のうちに、基板上でこれらの端子の位置を確認しておくと安心。

## 5. その他

- CPU: SH-2E（FPU付き 32bit RISC）、ビッグエンディアン。ROM内の 16/32bit 値・float はビッグエンディアンで解釈する。
- 内部クロックは入力クロックの PLL 逓倍（無印SH7058 は ×4 / ×8 を選択可能）。
- ECU側のCANコントローラは HCAN-II（第17章, p485〜）。PC側ツールの開発では通常参照不要。
- 命令セットの詳細は別冊「SH-2E ソフトウェアマニュアル」（RJJ09B0344）。ROMを逆アセンブルしてマップ位置を調べる段階で必要になる。
