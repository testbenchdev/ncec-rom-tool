NCEC ROM マップエディタ ヘルプ
================================

■ これは何か
2005 NCEC ロードスター(LF-VE / SH7058)の ROM(.bin、1MB)を、定義ファイル
(defs/libretuner/main.json + LFG7EG.json。無い場合は defs/lfg7eg.xml)に基づいてマップ(テーブル)
単位で表示・編集するエディタです。編集結果はファイルに保存します(チェックサムは保存時に自動再計算)。
ECUの吸い出し・照合・書き込み、ライブ計測などの実機機能はボタンから別途実行します。
詳しい説明は統合マニュアル docs/map_analysis_JA.html(目次付き。ブラウザで開く)にまとめてあります。

■ 起動
    NCEC_ROM_Editor.bat をダブルクリック(または python ncec_editor.py)
起動時に rom_data/ecu_readout_yahooauction.bin(ベンチECUの吸い出し原本)と定義(LibreTuner)を
自動で読み込みます。別のROMを開くときは「ROMを開く」ボタン(最初に rom_data フォルダが開きます)。
ROMは rom_data フォルダにまとめて置いてください。

■ 画面の構成
  ・メニュー : ファイル / 編集 / 表示 / 設定(v2.80〜)。各項目の右にショートカットキーを表示
  ・上部バー : [ROMを開く] [保存] [名前を付けて保存] などのボタンと、右端に「検索」欄
  ・左ペイン : カテゴリ別のテーブル一覧(ツリー)。カテゴリ名は日本語表示
  ・右ペイン : 表(マップ)を出すペイン。1画面・左右2分割・上下2分割・3分割・4分割を切り替えられ、
               各ペインの上に表名・アドレス・寸法・単位を表示(下の「表の分割表示」)
  ・説明エリア: アクティブなペイン(青い枠)の表の解説(カテゴリの役割)と詳細(型・軸の点数・単位・
                目安範囲・軸の入力 RAM)。メニュー「表示 → 説明欄を表示」(Ctrl+H)で隠せます
  ・最下部   : 左=ステータス(ファイル名 / 定義ID / チェックサム状態 / 未保存の有無・操作のお知らせ)、
               右=選択中のセルの位置・軸の値・値(複数セルなら 平均 / 最小 / 最大)

■ 基本操作
  1. 右のペインをクリックして選び(青い枠)、左ツリーで編集したいテーブルを選ぶ
  2. そのペインにマップが表示される(数値はスケーリング適用後の実値)
  3. セルをクリックして数字を打ち、Enter で確定(Enter / F2 / ダブルクリックでも入力を始められます)
     複数のセルを選んでから数字を打つと、選んだセルすべてに同じ値が入ります
  4. まちがえたら 元に戻す(Ctrl+Z)/ やり直し(Ctrl+Y)
  5. [保存] または [名前を付けて保存] で書き出し(チェックサムは自動で再計算)

■ 表の分割表示(レイアウト)と別ウィンドウ(v2.80〜)
  ・メニュー「表示」で 1画面(Ctrl+1)/ 左右2分割(Ctrl+2)/ 上下2分割(Ctrl+3)/ 4分割(Ctrl+4)/
    3分割=左1・右2(Ctrl+5)を切り替えます。ペインの境目はドラッグで自由に動かせます。
  ・ツリーで選んだ表は「アクティブなペイン」(青い枠)に出ます。ペインはクリック、または
    Ctrl+Tab / Ctrl+Shift+Tab で切り替えます。ツリーの右クリックで「ペイン N に表示」も選べます。
  ・各ペインの右上のボタン: ⇔ = 相方(制御側⇔監視側)を隣に表示、⧉ = 別ウィンドウで開く、× = ペインを空にする。
  ・別ウィンドウ(Ctrl+Shift+D)は自由に動かし、大きさを変えられます(複数可。好きな配置にできる)。
  ・表の拡大/縮小: Ctrl+ホイール、または Ctrl++ / Ctrl+- / Ctrl+0(標準)。ペインごとに覚えます。
  ・軸の見出し(上の X・左の Y)は固定で、表をスクロールしても見えたままです。
  ・レイアウト・各ペインの表と拡大率・別ウィンドウ・境目の位置は、終了時に保存して次回そのまま開きます
    (ui_settings.json。エディタとダッシュボードのウィンドウの位置と大きさもここに保存)。

■ 表の編集操作(選択・一括変更・元に戻す)(v2.80〜)
  選択: クリック / ドラッグ / Shift+クリック / Shift+矢印。行・列の見出しクリックで行・列ごと、
        左上の角(または Ctrl+A)で全体。Esc で選択を1セルに戻します。
  移動: 矢印(Ctrl+矢印 = 端まで)/ Home・End / Tab。
  一括の操作は、選んだセルすべてに効きます(未使用セル「—」は変えません)。
      増やす/減らす(小)…… + / -        増やす/減らす(大)…… PgUp / PgDn
      値を設定… =     値を加算… A     ％で増減… *     倍率を掛ける… M
      横に補間 H / 縦に補間 V / 四隅から2次元補間 B(端の値から、軸の値の間隔に合わせて直線で埋める)
      平滑化 S(周り3×3の平均)/ 下へコピー Ctrl+D / 右へコピー Ctrl+R
      コピー Ctrl+C / 貼り付け Ctrl+V(タブ区切り。表計算ソフトとやり取りできる。1つの値なら選択範囲すべてに)
      保存済みの値に戻す Ctrl+Shift+R / 運転点(●)のセルへ Space
  ・増減の幅は表ごとに自動で決まります(値の大きさに合わせる。整数の表は 1 以上)。
    「増減幅の設定…」(I)で表ごとに変えられ、次回も使われます。
  ・負の値を入れるときは Enter か F2 で入力を始めてから「-」を打ちます(「-」だけ押すと「減らす」)。
  ・元に戻す(Ctrl+Z)/ やり直し(Ctrl+Y・Ctrl+Shift+Z)は、セル・軸の編集とパッチ適用に効きます(300回分)。
    ROMを開き直すと履歴は消えます。
  ・保存してから変えたセルには左上に橙の印が付きます(表示 → 「保存後に変えたセルに印を付ける」で切替)。
  ・右クリックで、これらの操作をまとめたメニューが出ます(ショートカットキー付き)。
    WSL(WSLg)で起動したときは、メニューを別ウィンドウにせずエディタの画面の中に描きます(v2.81〜。WSLg では
    別ウィンドウのメニューが、外側を押すと一瞬消えて再び現れ、閉じても約1秒残るため)。外側をクリックすると閉じ、
    そのクリックは表には渡りません。項目のクリック・上下キーと Enter・Esc で操作します。Windows では通常のメニューです。

■ 制御側と監視側(ペア同時編集)(v2.80〜)
  電子スロットルやアイドル目標などには、安全監視(Data Integrity)側に同じ値の写しがある表があります
  (23組。どちらを開いても説明エリアとペインの上に相方の番地が出ます)。
  ・ペインの上の行に、相方と一致しているか(「全セル一致」/「⚠ N セル違います」)を出します。
    違うセルには右下に赤い印が付きます。
  ・⇔ ボタン(Ctrl+P)で相方を隣のペインに出します(1画面のときは左右2分割にします)。選択範囲は両方で
    そろうので、同じ場所を見比べられます。
  ・★「ペア同時編集」(表示メニュー。既定 ON)のあいだは、どちらの表を変えても相方の同じセルに同じ値を
    書きます(軸の編集・保存済みの値に戻す も同じ)。元に戻すと両方戻ります。
    OFF にすると表示中の表だけが変わり、相方との違いが赤い印で出ます。
  ・すでに違っている場所は、選んで「選択範囲を相方(制御⇔監視)へコピー」(右クリック)でそろえられます。
  ・寸法か型が違う組は照合も同時編集もしません(ペインの上に理由を出します)。

■ ショートカットキー(v2.80〜)
  メニュー「設定 → ショートカットキー…」で、操作ごとにキーを割り当てられます(1つの操作に複数可)。
  操作を選んで［キーを割り当て…］を押し、使いたいキーを押します。すでに使われているキーは、
  元の操作から外すか確認します。［この操作を既定に戻す］［すべて既定に戻す］もあります。
  ・「表」の操作は、表をクリックしてフォーカスがあるときだけ効きます(検索欄で文字を打つのを邪魔しない)。
  ・表の中の移動(矢印・Shift+矢印・Home/End・Tab)、数字と小数点(そのまま入力が始まる)は割り当てられません。
  ・ECU書き込みは、誤操作を防ぐためショートカットの対象外です(ボタンから)。
  既定のキー:
      ファイル : 開く Ctrl+O / 保存 Ctrl+S / 名前を付けて保存 Ctrl+Shift+S / 元に戻す Ctrl+Z / やり直し Ctrl+Y
      移動     : 検索欄 Ctrl+F / テーブル一覧 Ctrl+T / 表 Ctrl+E / 次・前のテーブル Ctrl+PgDn・Ctrl+PgUp
      表示     : レイアウト Ctrl+1〜5 / 次・前のペイン Ctrl+Tab・Ctrl+Shift+Tab / 相方 Ctrl+P /
                 別ウィンドウ Ctrl+Shift+D / ペインを閉じる Ctrl+W / 拡大・縮小・標準 Ctrl++・Ctrl+-・Ctrl+0 /
                 説明欄 Ctrl+H
      表の編集 : 上の「表の編集操作」のとおり(入力開始 F2・Enter、すべて選択 Ctrl+A、増減幅 I)
      ライブ   : Live F5 / ダッシュボード F6 / 記録 F8 / ログ分析 F9   その他: ヘルプ F1
  ・F5・F6・F8 などはダッシュボードのウィンドウでも効きます。

■ ヒートマップ(セルの色)
  値の大小を色で表します(低い=青系 → 高い=赤系)。色はそのテーブル内の最小〜最大で正規化。
  マップの傾向(山・谷)を視覚的に把握できます。

■ 検索(名前 / 0xアドレス)
  上部バー右の「検索」に文字を入れると、テーブル名・カテゴリ名(日本語/英語)で絞り込みます。
  空欄に戻すと全件表示に戻ります。
  「0x」で始めるとアドレス検索になります(v2.71〜):
    ・0xD6CDC      … その番地にあるテーブル(本体でも軸でも可。表の途中の番地でも見つかる)
    ・0xD6C        … 入力途中でも、その並びで始まる番地のテーブルに絞り込み
    ・0xFFFF6D5C   … RAM番地を入れると、その変数を軸の入力に使うテーブルを一覧(例 回転数 0xFFFF6D5C、負荷 0xFFFF6EC8、水温 0xFFFF6CC8)
                    照合するのは ROM のコードから求めたこの ROM の実番地(ncecu/axis_ram.py)。軸名の末尾の数字(例 RPM_6DD8)は
                    LibreTuner が使った別 ROM の番地で、この ROM の RAM とはずれているので使わない
  表を開くと、説明欄に「軸の入力 RAM(ROM のコードで確認)」として、その表の軸に入る RAM 番地が出ます(分かった表だけ)。

■ テーブルの種類
  ・1D : 単一の値(定数など)
  ・2D : 1軸のテーブル(例: 入力に対する1次元の出力)
  ・3D : X軸×Y軸のマップ(例: 回転数×負荷 の点火/燃料)。左端=Y軸、上端=X軸の見出し

■ 軸のラベルと見出しについて
  ・最上段の青いラベル「… →」= 横軸(X)が何か(例: 回転数 (RPM))。
  ・左上コーナーの青いラベル「↓ …」= 縦軸(Y)が何か(例: アクセル開度 (APP))。
  ・その内側のグレーの行(上)/列(左)= 軸の目盛(ブレークポイント)。参照用に表示します。
  ・中央のセル = マップ本体の値(ここを編集します)。
  軸ラベルは軸名から自動判定します(RPM/負荷/水温/吸気温/吸気圧/車速 など)。

■ 未使用セル(「—」表示)について
  値が「—」(グレー)のセルは、ROM上で未使用(0xFF)の領域です。このキャリブレーションで
  使っていない機能のマップで、ヒートマップの色計算からも除外されます。

■ ライブ計測とMAP追従(●)
  ・[Live ▶] で実機に接続すると、開いているマップ上に現在の運転点を ● で重ねて表示します(MAP追従)。
  ・●の位置に使う信号: 回転数 / エンジン負荷(絶対負荷 PID 0x43) / 水温 / 吸気温 / アクセル開度 / スロットル。
    負荷はマップの負荷軸と同じ「絶対負荷」を使います(計算負荷 PID 0x04 は別の量なので使いません)。
    アクセル開度は、ペダルセンサの生値(全閉約31%〜全開約72%)を 0〜100% に換算して使います。
  ・間引き: メニュー「設定 → ライブPID間引き…」で、信号ごとの読み出し間隔を選びます。
      選択肢(全項目共通): 毎回 / 0.1s / 0.2s / 0.5s / 1s / 2s / 5s / 10s / 無視
      「無視」= その信号を読まない。「毎回」を6個以内にすると1要求/周期になり最速です。
      同じ画面の下部で、ライブRAM読み出し(クラッチ/ブレーキ/KR/ノックレベル/排気温など)の間隔も設定できます。
  ・重複する信号は既定で「無視」です: 計算負荷(0x04)、APP E(0x4A)、ブレーキ2。必要なら間引き設定で戻せます。
  ・表示中のマップの軸に使う信号は、「無視」や遅い設定にしていても自動で読みます(MAP追従を止めないため)。
  ・ライブRAM(Mode23)は1周期に2ブロックまで、遅れの大きい順に読みます(回転・負荷の更新を遅くしないため)。
  ・設定は live_intervals.json / ram_reads.json に保存され、次回も復元されます。
  ・ダッシュボードはタイルを右クリックで表示方式(数値/棒/メーター/グラフ)・更新周期・表示範囲・アラームを
    変更できます(WSL では右クリックメニューを画面の中に描き、「表示方式」「更新周期」は行をクリックすると下に開きます。v2.81〜)。
    ウィンドウの位置と大きさは前回のまま開きます(v2.80〜)。記録したログは
    「設定 → ログ分析チャート…」で複数チャンネルを縦に並べて分析できます。
  ・●は表示中のすべてのペイン(別ウィンドウを含む)に出ます。軸に使う信号は全ペインの分を読みます。

■ パッチ適用(メニュー「設定 → パッチ適用」)
  どのパッチも、メモリ上のROMだけを変更します(保存するまでファイルは不変)。適用後に、変更した
  map データを一覧(リザルト)で表示します。未対応のROMには適用を拒否します。

  ・フラットシフト(点火カット/遅角)
      方式(0=点火遅角 / 1=点火カット)・ゲート・test_mode を指定して適用。
      発動条件: クラッチ踏込 かつ アクセル開度>しきい値 かつ 回転>しきい値 かつ 車速>下限 の間だけ。
      RAMにもレジスタにも書き込まない読み取り専用設計です。
      値の変更は、左ツリーの『パッチ - フラットシフト』(適用済みROMのときだけ表示)。
      test_mode=1 は停車確認用(車速ゲートだけ無視)。走行前に必ず 0 へ。

  ・アンチラグ(アクセルオフ時のオーバーランのポップ/バーブル)
      A. DFCO無効(全回転バーブル) — 減速燃料カットを常時オフ＋減速点火を深く遅角。一番簡単。
      B. RPMゲート ★おすすめ — DFCO有効のまま、有効回転数より上だけ燃料を残してポップ。
      C. RPMゲート＋ツキ重視 — B と同じ回転ゲート(DFCO有効)に、浅い遅角＋点火/燃料の復帰を速く。
      D. ツキ重視・DFCO無効 — v2.70 までの「C」。
      B・C は「アンチラグ有効回転数」を 1500〜6000rpm・100rpm刻みで設定できます(既定3000)。
      有効回転数以下は無音、超えると効き始め、+1000rpm で完全に有効。
      ⚠ 排気管内で燃料を燃やす＝触媒・排気系の熱害。純正触媒/マフラー車の常用は非推奨。

  ・回転落ち高速化(レブハング低減)
      シフトアップ時の回転落ちを速くします(減速燃料カットを早く・強く)。燃料側だけの変更で、
      電子スロットルには触りません。プリセット(off/mild/strong)または数値で指定。

  ・電スロチューニング(電子スロットルの1:1化)
      ペダルマップ(アクセル→スロットル)を1:1寄りに立ててワイヤースロットル風に。
      blend(0=純正〜1=完全1:1)・指令上限の引き上げ[%]・アイドル直上で残す列数 を指定して適用。
      制御と安全監視(Data Integrity)の両コピーを同値で更新します(片方だけだとフェイルセーフ)。
      ⚠ 2速低回転の50%上限(トラクション保護)は1:1化で外れます。

■ アイドル回転(目標回転)を変えるとき
  パッチは不要で、ツリーの『アイドル回転 - ベース(Idle Speed - Base)』を直接編集します。
  走行(In-Gear)/非走行(Not In-Gear)それぞれに「制御側 (Control)」と「監視側」の2枚があります。
  ★必ず2枚を同じ値にしてください(片方だけ変えると監視不一致でフォルトになり得ます)。
  (写しのある表は、どちらを開いても説明エリアに相方の番地が出ます。スロットル系も同じです)
  ⇔ ボタンで2枚を並べ、「ペア同時編集」が ON なら片方を変えるだけで両方が同じ値になります(上の節)。
      走行   : 制御 0xD6C9C / 監視 0xF4DEC      非走行 : 制御 0xD6CDC / 監視 0xF4E2C
  検索欄に 0xD6C9C のように番地を入れるとすぐ開けます。
  目標回転が動く“速さ”(スルーレート 0xD6AB8 ほか)は安全監視が保護しているので触らないでください
  (実車で DTC P0606 とスロットルのリンプを確認済み)。

■ 電動ファンの作動水温を変えるとき
  ツリーの『電動ファン制御(Engine Fan Control)』にある水温しきい値は、℃ ではなく水温センサ電圧の
  A/D 値です(電圧 = 値×5÷1024)。水温が高いほど電圧が低いので、★値が大きいほど低い水温を表します。
      値を大きくする → 低い水温で回り始める(早く回る)
      値を小さくする → 高い水温になるまで回らない
  表を開くと、説明エリアに換算が出ます(いまの値が何℃で入り切りするか・式・目安表)。
  値を確定するとその場で更新されます。換算には、開いている ROM の水温変換曲線
  (ECT Scaling - Voltage to ECT)を使います。
      目安  : 85℃≈143 / 90℃≈125 / 95℃≈109 / 100℃≈96 / 105℃≈84 / 110℃≈74   (1 は約0.4℃)
      純正  : 中速 96/103 = 100℃でON・97℃でOFF、高速 77/84 = 108℃でON・105℃でOFF(実車純正ROMの値)
  ・作動側(Activation / Enable)は、停止側(Deactivation / Disable)より小さい値にします。
    同じか大きくすると入り切りの幅が無くなり、説明エリアに警告が出ます。
  ・対象は、走行中の中速/高速(AC Off)の4表と、アフタークーリングの低速/中速/高速の6表です(単位表示は A/D)。
    車速しきい値(km/h)は値そのままです。タイマは秒ではなくカウントで、遷移遅延は 25ms ごと、
    アフタークーリングのタイマは 100ms ごとに 1 減ります(説明エリアに秒の換算が出ます。1ms の刻みと
    25ms のサブタスクは 2026-11-17 に実車で確認。ファンが実際に入り切りする水温・時間は未計測)。
  ・この4つのしきい値に監視側の写しはありません(それぞれ1か所で参照)。
  ・検索欄に 0xBF9F8 と入れると中速の作動しきい値が開きます(0xBF9FA / 0xBF9FC / 0xBF9FE が続きの3つ)。

■ チェックサムについて
  ROM には整合性チェックのための内部チェックサム(全35領域)があります。
  セルを編集すると一時的に不整合になりますが、[保存] 時に自動で再計算して整合させます。
  ステータス欄でチェックサムの状態を確認できます。

■ 安全上の注意
  ・編集・保存はファイル上だけで行います。実機への書き込みは [ECU書き込み] を押したときだけです
    (書き込み中は電源を切らない)。
  ・編集前の ROM は必ずバックアップを取ってください([名前を付けて保存] で別名保存推奨)。
    吸い出した原本は rom_data フォルダに残しておきます。
  ・フラッシュメモリの書き換え保証回数は最小100回です。実機へ書き戻す場合は、
    変更をまとめてから行い、無駄な書き込みを避けてください。
  ・値はスケーリング(toexpr)で実値に変換して表示しています。極端な値は入力しないでください。
  ・排ガス関連の監視(O2/触媒/EGR など)やDTCを無効化する用途は対象外です。

■ うまく動かないとき
  ・文字化けする → 日本語フォント(Meiryo UI 等)が無い環境では表示が乱れることがあります。
  ・定義にないマップは表示されません(例外: パッチの追加項目。ncecu の各パッチモジュールで定義)。
  ・ショートカットが効かない → 表をクリックしてから押してください(「表」の操作は表にフォーカスが必要)。
    検索欄などで文字を打っているあいだは、Ctrl/Alt 付きのキーと F キーだけが効きます。
  ・レイアウトや別ウィンドウの配置を最初に戻したい → エディタを閉じてから ui_settings.json を削除します。
  ・Live の更新が遅い → 「設定 → ライブPID間引き…」で、使わない信号を「無視」にしてください。
  ・書き込みに失敗した → これまでの失敗はすべて、電源を入れ直してもう一度書き込むことで復旧できています
    (統合マニュアルの「書き込み」章)。
