NCEC ROM マップエディタ ヘルプ
================================

■ これは何か
2005 NCEC ロードスター(LF-VE / SH7058)の ROM(ncec_rom_dump.bin)を、定義ファイル
(defs/libretuner/main.json + LFG7EG.json。無い場合は defs/lfg7eg.xml)に基づいてマップ(テーブル)
単位で表示・編集するエディタです。編集結果はファイルに保存します(チェックサムは保存時に自動再計算)。
ECUの吸い出し・照合・書き込み、ライブ計測などの実機機能はボタンから別途実行します。
ライブ計測では、変化のゆっくりしたPID（水温・電圧など）を一定間隔でのみ問い合わせて間引き、回転数など速いPIDの更新を速くしています（既定の間隔は ncecu/livelog.py の DEFAULT_PID_INTERVALS）。
間隔はメニュー「設定 → ライブPID間引き…」でPIDごとに変更できます（毎回／0.5／1／2／5／10秒）。同じ画面の下部で、ライブRAM読み出し（KR／クラッチ／排気温／ノックカウント／強度／リタード）の読み出し間隔も設定できます。
ダッシュボードはタイルを右クリックで表示方式（数値/棒/メーター/グラフ）・更新スタイル（なめらか）・表示範囲・アラームを変更できます。記録したログは「設定 → ログ分析チャート…」で複数チャンネルを縦に並べて分析できます。「毎回」を6個以内にすると1要求/周期になり最速です。設定は live_intervals.json に保存され、次回も復元されます。

■ 起動
    python ncec_editor.py
起動時に、同じフォルダの ncec_rom_dump.bin と定義(LibreTuner)を自動で読み込みます。
別のファイルを開くときは「ROMを開く」ボタンを使います。

■ 画面の構成
  ・上部バー : [ROMを開く] [保存] [名前を付けて保存] と、右端に「検索」欄
  ・左ペイン : カテゴリ別のテーブル一覧(ツリー)。カテゴリ名は日本語表示
  ・右ペイン : 選んだテーブルの内容(2D/3Dマップ)。上に表名・アドレス・単位・型を表示
  ・説明エリア: マップを開くと、そのマップの解説(カテゴリの役割)と詳細(型・軸の点数・単位・
                目安範囲)を表示。何のマップか分からないときの手がかりになります
  ・最下部   : ステータス(ファイル名 / 定義ID / チェックサム状態 / 未保存の有無)

■ 基本操作
  1. 左ツリーでカテゴリを開き、編集したいテーブルを選ぶ
  2. 右側にマップが表示される(数値はスケーリング適用後の実値)
  3. セルをクリックして数値を入力し、Enter(または他セルへ移動)で確定
  4. [保存] または [名前を付けて保存] で書き出し(チェックサムは自動で再計算)

■ ヒートマップ(セルの色)
  値の大小を色で表します(低い=青系 → 高い=赤系)。色はそのテーブル内の最小〜最大で正規化。
  マップの傾向(山・谷)を視覚的に把握できます。

■ 検索
  上部バー右の「検索」に文字を入れると、テーブル名・カテゴリ名(日本語/英語)で絞り込みます。
  空欄に戻すと全件表示に戻ります。

■ テーブルの種類
  ・1D : 単一の値(定数など)
  ・2D : 1軸のテーブル(例: 入力に対する1次元の出力)
  ・3D : X軸×Y軸のマップ(例: 回転数×負荷 の点火/燃料)。左端=Y軸、上端=X軸の見出し

■ 軸のラベルと見出しについて
  ・最上段の青いラベル「… →」= 横軸(X)が何か(例: 回転数 (RPM))。
  ・左上コーナーの青いラベル「↓ …」= 縦軸(Y)が何か(例: アクセル開度 (APP))。
  ・その内側のグレーの行(上)/列(左)= 軸の目盛(ブレークポイント)。参照用に表示します。
  ・中央のセル = マップ本体の値(ここを編集します)。
  軸ラベルは軸名から自動判定します(RPM/負荷/水温/吸気温/吸気圧/車速 など)。

■ 未使用セル(「—」表示)について
  値が「—」(グレー)のセルは、ROM上で未使用(0xFF)の領域です。このキャリブレーションで
  使っていない機能のマップで、ヒートマップの色計算からも除外されます(詳細はQ&A)。

■ フラットシフト(点火リタード)
  ・[フラットシフト] ボタン: 開いているROMに、フラットシフト用の点火リタード・パッチ(第3ドラフト)を
    当てます。確認ダイアログの後、メモリ上のROMだけを変更します(保存するまでファイルは変わりません)。
    ※旧称は[点火リタード]。
    既に当たっているROMでは何もせず、値の場所を案内します。未対応ROM・別パッチと衝突するROMは拒否します。
  ・発動条件: クラッチ踏込 かつ アクセル開度>しきい値 かつ 回転>しきい値 かつ 車速>下限 の間だけ、
    最終進角からリタード量を引きます(純正の最大リタードで下限制限)。
  ・値の変更: 左ツリーの『パッチ - フラットシフト（点火リタード）』に4項目が出ます
    (アクセル開度しきい値 / 回転しきい値 / 車速下限 / リタード量)。パッチ適用済みROMのときだけ表示。
  ・『リミッタ - 回転数(レブリミット)』には、純正の停車中スロットルカットの『車速しきい値』(@0xC53B8、
    純正2.0km/h)と『ヒステリシス』(@0xC53C4)も追加項目として表示します(定義には無い項目)。
  ・追加項目は範囲外の値を受け付けません(入力すると警告して元に戻します)。
  ・点火制御を書き換えるパッチです。実機では未検証のベンチ検証用ドラフトなので、予備/ベンチECUで確認してください。

■ アンチラグ(アクセルオフ時のオーバーランのポップ/バーブル)
  ・[アンチラグ] ボタン: 減速時に「パンパン」鳴らすパッチ。有効化方法を A/B/C から選びます。
      A. DFCO無効(全回転バーブル) — 減速燃料カットを常時オフ＋減速点火を深く遅角。一番簡単。
      B. RPMゲート(3000rpm超だけ)★おすすめ — 燃料の残り方をRPMで分け(低回転=無音/高回転=ポップ)＋遅角。
      C. ツキ重視 — 遅角を浅く＋点火/燃料の復帰を速く＋DFCO無効。ポップ控えめ、レスポンス優先。
  ・適用後、変更した map データを一覧(リザルト)で表示します(未保存。保存時にチェックサム自動補正)。
  ・⚠ 排気管内で燃料を燃やす＝触媒・排気系の熱害。純正触媒/マフラー車の常用は非推奨。詳細は docs/tuning_overrun_pops_ja.md。

■ 電スロチューニング(電子スロットルの1:1化)
  ・[電スロチューニング] ボタン: ペダルマップ(アクセル→スロットル)を1:1寄りに立ててワイヤースロットル風に。
    blend(0=純正〜1=完全1:1)・指令上限の引き上げ[%]・アイドル直上で残す列数 を指定して適用。
    制御と安全監視(Data Integrity)の両コピーを同値で更新します(片方だけだとフェイルセーフ)。
  ・適用後、変更した map データ(全ギアのペダルマップ＋指令上限)をリザルト表示します。
  ・⚠ 2速低回転の50%上限(トラクション保護)は1:1化で外れます。詳細は docs/tuning_throttle_ja.md。
    詳細は docs/tuning_flatshift_ja.md。

■ チェックサムについて
  ROM には整合性チェックのための内部チェックサム(全35領域)があります。
  セルを編集すると一時的に不整合になりますが、[保存] 時に自動で再計算して整合させます。
  ステータス欄でチェックサムの状態を確認できます。

■ 安全上の注意
  ・編集・保存はファイル上だけで行います。実機への書き込みは [ECU書き込み] を押したときだけです
    (予備/ベンチECU推奨。書き込み中は電源を切らない)。
  ・編集前の ROM は必ずバックアップを取ってください([名前を付けて保存] で別名保存推奨)。
  ・フラッシュメモリの書き換え保証回数は最小100回です。実機へ書き戻す場合は、
    変更をまとめてから行い、無駄な書き込みを避けてください。
  ・値はスケーリング(toexpr)で実値に変換して表示しています。極端な値は入力しないでください。

■ うまく動かないとき
  ・文字化けする → 日本語フォント(Meiryo UI 等)が無い環境では表示が乱れることがあります。
  ・定義にないマップは表示されません(例外: フラットシフト関連の追加項目。ncecu/flatshift.py で定義)。
  ・大きいテーブル(例 41×37)は初回表示に数秒かかることがあります。
  ・保存した ROM が実機で弾かれる → チェックサムは自動補正されますが、
    書き込み(フラッシュ)側の手順は別途(本プロジェクトのフラッシュ機能)を参照。
