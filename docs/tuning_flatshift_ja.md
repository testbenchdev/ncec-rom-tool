# フラットシフト（ノーリフトシフト）調整ガイド

WOT（全開）のままクラッチを踏んでアップシフトする「ノーリフトシフト」の実装メモ。

> ⚠ 予備/ベンチまたは自分の車両で。実走での確認・詰めが前提。公道・法規・駆動系への配慮は自己責任。

> **⚠ 2026-10-16 訂正**:v1.10 で「`@0x0C53BC` を上げるだけでフラットシフトになる」と書いたが誤り。純正のクラッチ連動スロットルカットは**車速2km/h未満（停車中）でしか効かない**（下記）。走行中のシフトでは何も起きない。走行中のフラットシフトは「点火カット/遅角方式（最終設計・読み取り専用。2026-11-01に実車で両方式を確認）」で実装。

## 純正のクラッチ連動スロットルカット（`@0x0C53BC`）の正体

ルーチン `0x097346`（〜`0x097B84`）の判定:

```
リミット = (車速 < @0x0C53B8 かつ クラッチ踏込) ? @0x0C53BC : @0x0C53C0
フラグ 0xFFFF3827 = RPM > リミット（前回成立中は −@0x0C53C4 のヒステリシス）
```

| 番地 | 名称 | 純正値 | 意味 |
|---|---|---|---|
| `@0x0C53B8` | 車速しきい値 | **2.0 km/h** | これ未満のときだけ CPP set のリミットを使う |
| `@0x0C53BC` | Rev Limit Throttle Cut \| CPP set | 6500 rpm | **停車中**にクラッチを踏んで空ぶかしした時のスロットルカット回転 |
| `@0x0C53C0` | Rev Limit Throttle Cut \| CPP clear | 10000 rpm | それ以外（走行中・クラッチ離し）＝実質無効 |
| `@0x0C53C4` | ヒステリシス | 100 rpm | |
| `@0x0C487C` | Rev Limit Fuel Cut \| MT | 7500 rpm | 通常のレブリミット（燃料カット） |

エミュレータで純正ルーチンを実行して確認した結果（クラッチ踏込時の `0xFFFF3827`）:

| RPM | 車速 0 | 1.9 km/h | 2.1 km/h | 60 km/h |
|---|---|---|---|---|
| 6000 | 0 | 0 | 0 | 0 |
| 6600 | **1** | **1** | 0 | 0 |
| 7100 | **1** | **1** | 0 | 0 |

- クラッチを離していれば、どの車速でもフラグは立たない。
- **v1.10 で作ったサンプルROM（7000rpm 設定）の実体**は「停車中クラッチ踏込時の空ぶかしを7000rpmで抑えるリミッタ」。走行中のシフトには効かない。
- 裏返すと、`@0x0C53BC` は**停車中専用のスロットルカット式リミッタ＝ローンチ用回転リミッタとしてそのまま使える**（例:4500に下げる）。2km/hを超えた時点で解除される。要実走確認。

## 点火カット/遅角方式（第6ドラフト＝スクラッチ無し・読み取り専用・ベンチ検証用）

走行中、**クラッチ踏込 かつ 回転>しきい値 かつ アクセル>しきい値 かつ 車速>下限** の間だけ **点火遅角（大遅角も調整可）** か **本物の点火カット（スパーク停止）** でトルクを落とす方式。**点火制御のコードパッチ**なので実走前にベンチで確認必須。

> ⚠ **点火カット（方式1）はベンチ/エミュでは「本当に火が止まるか」を証明できない**（ATUの発火ハードを模擬できないため）。実車でのみ確認できる。手順は `下の「実車テスト手順」`。

> ★ **なぜ窓なし・スクラッチ無しか**：当初はハードタイマ(TCNT2B)でms窓を測り状態をRAMに保持する設計（draft4/5）だったが、**実車でMode23可視RAMに安定して書ける空きが存在しない**と判明（0xFFFFC900〜CE00等は走行で中身が動くRTOSスタック/バッファ。走行スキャンで連続16Bの不変空きゼロ）。ATUレジスタはMode23で検証できず誤書込＝エンジン損傷で不採用。→ **RAMにもレジスタにも一切書き込まない読み取り専用設計**に変更。固定スクラッチが無いので衝突/文鎮化リスクが原理的にゼロ。窓時間はクラッチを踏んでいる長さ＝ドライバが制御（回転しきい値が上限としても働く）。

### 点火の経路（2026-10-16 / 発火経路は 2026-10-26 追補）

| 段 | 場所 | 内容 |
|---|---|---|
| 1 | タスク `0x4D8DA` | 最終進角 = clamp(`0x7AE0`+`0x7B98`+`0x7DA4`, 最大リタード `0x7AFC`, 最大進角 `@0xCE20C`) → **`0xFFFF7AA4`**（クランプは `0x4D9D0` で helper `0x2404`） |
| 2 | タスク `0x4D84E` | `0x7AA4` → レート制限 → `0xFFFF7AA0`（PID 0x0E の元）→ 気筒別補正 → **気筒別点火値 `0xFFFF7AC8/7ACC/7AD0/7AD4`** |
| 3 | `0x19B44` | 気筒別点火値から点火イベント角度を計算（(進角−9.8)×65536） |
| 4（発火） | 状態機械（設定表 `0x2DE98/0x2DEA4` の関数ポインタ）→ ATU出力コンペアでコイル**充電→発火**。充電ハンドラ `0x19D04`（ポインタ格納 `0x2DEB0`）＝**コイル充電スケジュール**（末尾で `struct[1]=1/struct[2]=0` 記帳して rts） |

### 仕組み（2つのケーブ・どちらもRAM非書込）

**ケーブ1（進角クランプ・フック, `0xDE200`）**— 遅角方式。
- `0x4D9D0` のクランプ呼び出しが使うリテラル `@0x4DA98`(=`0x2404`) をケーブ1へ差し替え。
- ケーブ1は**その場でECU状態を読んで判定**：方式==0 かつ クラッチ踏込 かつ APP>しきい値 かつ RPM>しきい値 かつ（test_mode または 車速>下限）なら `fr4 -= retard`、`fr5 = floor`（クランプ下限を下げるので純正の最大リタードに縛られず深く＝大遅角）。純正クランプ `0x2404` へ末尾ジャンプ。`fr5` は jsr 遅延スロット `0x4D9D2` で `@r14` から再ロード済・クランプ後 `0x4D9D4` で上書きされ再利用されないので書換え安全。方式==1（カット）や非成立なら進角を触らずクランプへ。
- 使用レジスタ r1 / fr0,fr1,fr5,fr7。r13/r14/fr6 不可侵。

**ケーブ2（コイル充電ハンドラ差し替え, `0xDE400`）**— 本物の点火カット。
- 発火状態機械の設定表の「充電ハンドラ `0x19D04`」ポインタ（格納番地 `0x2DEB0`）をケーブ2へ差し替え（表に1回だけ＝クランプ同様に差替え可能）。
- ケーブ2も**その場で判定**：方式==1 かつ クラッチ踏込 かつ APP>しきい値 かつ RPM>しきい値 かつ（test_mode または 車速>下限）なら、充電本処理を飛ばして `0x19D04` の末尾記帳（`struct[1]=1/struct[2]=0`、`r4`=構造体）だけ実施し rts＝**そのサイクルの充電スキップ＝コイル未通電＝火花なし**。非成立なら純正 `0x19D04` へそのまま jmp（素通り）。
- 未通電狙いなので**コイル過熱もしない**想定（＝発火側を止めるより安全）。ただし「`0x19D04` が充電か発火か・毎サイクル呼ばれるか」は実車のみ確認可（下記）。

### 発動条件（ゲート）と CAL 一覧（定数は `0xDE300〜`）

発動＝**クラッチ `0xFFFF7100`=1 かつ APP>`@0xDE300` かつ RPM>`@0xDE304` かつ 車速>`@0xDE308`** の間だけ。`test_mode=1` は**車速ゲートだけ無視**（クラッチ＋APP＋RPM は生かす）＝停車確認用。始動/アイドルは低回転でゲート不成立なので発動せず（＝クラッチ始動を妨げない）、停車ニュートラルで回転を上げると発動。

| 番地 | CAL | 型 | 既定 | 範囲 |
|---|---|---|---|---|
| `@0xDE300` | APP しきい値 [%]（RAM `0xFFFF56C8`） | float | 80 | 0〜100 |
| `@0xDE304` | RPM しきい値 [rpm]（RAM `0xFFFF6D5C`） | float | 7000 | 1000〜8000 |
| `@0xDE308` | 車速下限 [km/h]（RAM `0xFFFF6D04`） | float | 10 | 0〜250 |
| `@0xDE30C` | 遅角量 [°]（遅角方式） | float | 20 | 0〜60 |
| `@0xDE310` | 下限=最小進角 [°]（遅角方式。負=ATDC） | float | −10 | −30〜20 |
| `@0xDE314` | 方式（0=遅角 / 1=点火カット） | uint32 | 0 | 0〜1 |
| `@0xDE318` | **デバッグ test_mode**（1=車速ゲートだけ無視・クラッチ+回転+アクセルで発動・停車確認用） | uint32 | 0 | 0〜1 |

- 方式0=点火遅角：最終進角から `retard`[°] を引く。下限 `floor`[°] まで（純正の最大リタードを越えて深く＝大遅角もこの量で調整）。
- 方式1=点火カット（本物のスパーク停止）：発動中コイル充電をスキップ＝火花なし。進角は不変。**生ガス→バックファイア/高EGT**。
- 走行中はクラッチを踏んでも純正スロットルカットは入らない（CPP clear=10000rpm）のでスロットルは開いたまま。RPMしきい値が上限として働く。
- ⚠ クラッチ番地訂正: 旧 `0xFFFF6FCC` は減速ステータスの誤認。実車RAM差分（`tools/ram_diff.py`）で本物のクラッチ `0xFFFF7100` を特定（v2.40）。

### 停車デバッグ（test_mode）

`test_mode=1` のとき、**車速ゲートだけ無視**し、クラッチ＋回転＋アクセルで発動。始動/アイドルは低回転でゲート不成立なので発動せず（＝クラッチ始動を妨げない）、**停車ニュートラルでアクセルをあおり回転をRPMしきい値以上に上げると発動**する。停車確認用に RPMしきい値を低め（例3000rpm）・APPしきい値も低め（例15%）にしておくと軽い空ぶかしで効果を確認できる。**走行では必ず 0 に戻す**（低速/停車でも回転＋アクセル条件を満たすとカットするため）。確認は `tools/flatshift_debug.py`（Mode23で**クラッチ**、OBDで**RPM・バッテリ電圧**を監視。回転頭打ち＝カット効果／電圧維持＝充電スキップ(安全)／電圧ドロップ＝発火停止の疑い(過熱・即離脱)）＋タイミングライト。スクラッチが無いので内部フラグ(cut_active/skip_count)は読めず、判定は「効果」で行う。詳細は `下の「実車テスト手順」`。

### 検証状況

- 生成した両ケーブを逆アセンブルして全命令一致。RAM/レジスタへの書き込みは無し（cave2の `struct[1]/[2]` 記帳は純正 `0x19D04` の契約どおりの構造体更新で、スクラッチではない）。
- SH2エミュ（`ncecu/sh2emu.py`）でケーブ**ロジック**を全分岐検証・全件一致:
  - ケーブ1（遅角）: ゲート成立で `fr4−retard`、下限 `floor` で大遅角（純正下限10を越える）/ 方式1では進角不変 / ゲート不成立(クラッチ/回転/アクセル/車速)で無効 / test_mode=1は車速だけ無視（車速0でも回転+アクセルあれば発動・低回転は不発・クラッチOFFは素通り）。
  - ケーブ2（カット）: 方式1かつゲート成立で `docut`（記帳して rts）/ 方式0・ゲート不成立で `0x19D04` へ素通り / test_mode=1は車速だけ無視（同上）。
  - ※付随して `sh2emu` の STS デコードのバグ（実ISA `0x0n1A`=MACL/`0x0n2A`=PR）を修正。seed→key 自己検証は修正後も一致。
- **実車でのみ確認できる事項**（手順 `下の「実車テスト手順」`）:
  - 点火カットが実際に火を止めるか（`0x19D04`＝充電の読みが正しいか）。タイミングライト＋RPM低下で確認。
  - **コイル過熱の有無**＝電圧ドロップで監視（発火側を止めていた場合の危険検知）。

### 既知の制限 / 次段

- 点火カットの「`0x19D04`＝充電」は実車未確認（過熱リスクの最終判定は実車・電圧監視＋タイミングライト）。
- ms単位の窓は無い（クラッチを踏んでいる長さ＝窓。正確なms制限が要るなら安定スクラッチが必要だが本ECUには存在しない）。
- RPMしきい値にヒステリシスが無い。遅角量・下限は全回転・全ギア一律。
- 半クラッチでもクラッチスイッチが入れば発動しうる（回転/アクセル/車速ゲートで絞る）。
- 安全/法規: 点火カットは生ガスを排気へ＝バックファイア/高EGT。触媒・排気系の熱害注意。クラッチ操作は短く。

## 実車テスト手順（フラットシフト（第6ドラフト）実車テスト手順）

点火遅角／**本物の点火カット**（`ncecu/flatshift.py` 第6ドラフト＝スクラッチ無し・読み取り専用）を実機に投入する前の確認手順。設計の詳細は `docs/tuning_flatshift_ja.md`。

> ⚠ **点火カット（方式1）はベンチ/エミュでは「本当に火が止まるか」を証明できない**（ATUの発火ハードを模擬できないため）。コイル充電ハンドラ `0x19D04` を差し替えて「充電スキップ＝火花なし」を狙うが、もし `0x19D04` が充電でなく発火だった場合、スキップすると**コイル通電しっぱなし＝過熱**の恐れ。→ 下記で**電圧**を見て安全確認してから使うこと。消火器・電源遮断の準備を。まずベンチ/予備ECU。元の吸い出しROMは保管。公道・騒音・排ガスは自己責任。

> ✅ この設計は **RAMにもレジスタにも一切書き込みません**（固定スクラッチ無し）。実車で安定した空きRAMが存在しなかったため、両ケーブが毎回ECU状態を読んでその場で判定します。スクラッチRAMの空き確認・tick/ms校正・窓設定は**不要**になりました。

### テスト方法（③で行うこと）

`test_mode=1` は**車速ゲートだけ無視**し、クラッチ＋回転＋アクセルで発動します（始動/アイドルは低回転でゲート不成立＝発動しないので、普通に始動・アイドルできます＝クラッチ始動を妨げません）。**ニュートラルのままクラッチを踏み、アクセルを軽くあおって回転をRPMしきい値以上に上げる**と発動します。停車確認用に RPMしきい値を低め（例3000rpm）・APPしきい値も低め（例15%）にしておくと軽い空ぶかしで確認できます。あおり中の値で判定：

| 観察 | 意味 | 対応 |
|---|---|---|
| 回転がしきい値付近で頭打ち／ばらつく／あおっても伸びない | 点火が止まっている＝**カット効果あり** | 続行 |
| **電圧が維持** | コイル未充電＝「充電スキップ」で想定どおり（安全） | OK |
| **電圧が大きくドロップ** | コイル通電しっぱなしの疑い＝「発火」を止めた可能性＝過熱 | **即アクセル/クラッチを離し `test_mode=0` へ・使用中止して報告** |
| あおって回転がしきい値を超えても素通りで吹け上がる | しきい値が高すぎる、または充電ハンドラ `0x19D04` が呼ばれていない可能性 | しきい値を下げて再確認→それでも駄目なら報告（別ハンドラへ再フック要） |

- **最終確認**：タイミングライトを#1プラグに当て、踏込中に**発火（フラッシュ）が消える**こと。これが確実な判定。
- ※スクラッチが無いので `skip_count`/`cut_active` のような内部フラグは読めません。判定は上記の「効果」で行います。

---

### ④ 本番化

確認できたら、エディタのツリーで 方式・ゲート（回転/アクセル/車速）・遅角量/下限 を本番値にし、**`test_mode=0` を必ず確認**（1のままだと車速条件を無視するので、停車・低速でも回転を上げてクラッチを踏むと誤発動する）、保存→書き込み。
- 目安：遅角 15〜20°（下限 −10°前後）、ゲートは実運用のしきい値（既定 7000rpm / 80% / 10km/h）。
- 窓時間の設定はありません（クラッチを踏んでいる間だけ＝ドライバのクラッチ操作が窓）。
