# フラットシフト（ノーリフトシフト）調整ガイド

WOT（全開）のままクラッチを踏んでアップシフトする「ノーリフトシフト」の実装メモ。

> ⚠ 予備/ベンチまたは自分の車両で。実走での確認・詰めが前提。公道・法規・駆動系への配慮は自己責任。

> **⚠ 2026-10-16 訂正**:v1.10 で「`@0x0C53BC` を上げるだけでフラットシフトになる」と書いたが誤り。純正のクラッチ連動スロットルカットは**車速2km/h未満（停車中）でしか効かない**（下記）。走行中のシフトでは何も起きない。走行中のフラットシフトは「点火リタード方式（第3ドラフト）」で開発中。

## 純正のクラッチ連動スロットルカット（`@0x0C53BC`）の正体

ルーチン `0x097346`（〜`0x097B84`）の判定:

```
リミット = (車速 < @0x0C53B8 かつ クラッチ踏込) ? @0x0C53BC : @0x0C53C0
フラグ 0xFFFF3827 = RPM > リミット（前回成立中は −@0x0C53C4 のヒステリシス）
```

| 番地 | 名称 | 純正値 | 意味 |
|---|---|---|---|
| `@0x0C53B8` | 車速しきい値 | **2.0 km/h** | これ未満のときだけ CPP set のリミットを使う |
| `@0x0C53BC` | Rev Limit Throttle Cut \| CPP set | 6500 rpm | **停車中**にクラッチを踏んで空ぶかしした時のスロットルカット回転 |
| `@0x0C53C0` | Rev Limit Throttle Cut \| CPP clear | 10000 rpm | それ以外（走行中・クラッチ離し）＝実質無効 |
| `@0x0C53C4` | ヒステリシス | 100 rpm | |
| `@0x0C487C` | Rev Limit Fuel Cut \| MT | 7500 rpm | 通常のレブリミット（燃料カット） |

エミュレータで純正ルーチンを実行して確認した結果（クラッチ踏込時の `0xFFFF3827`）:

| RPM | 車速 0 | 1.9 km/h | 2.1 km/h | 60 km/h |
|---|---|---|---|---|
| 6000 | 0 | 0 | 0 | 0 |
| 6600 | **1** | **1** | 0 | 0 |
| 7100 | **1** | **1** | 0 | 0 |

- クラッチを離していれば、どの車速でもフラグは立たない。
- **`ncec_flatshift_7000.bin`（v1.10）の実体**は「停車中クラッチ踏込時の空ぶかしを7000rpmで抑えるリミッタ」。走行中のシフトには効かない。
- 裏返すと、`@0x0C53BC` は**停車中専用のスロットルカット式リミッタ＝ローンチ用回転リミッタとしてそのまま使える**（例:4500に下げる）。2km/hを超えた時点で解除される。要実走確認。

## 点火リタード方式（第3ドラフト・ベンチ検証用）

スロットルを開けたまま（吸気流速を保ったまま）点火時期を遅らせてトルクを落とす方式。**点火制御のコードパッチ**なので、実走前にベンチでの確認が必須。

### 点火の経路（2026-10-16 確定）

| 段 | 場所 | 内容 |
|---|---|---|
| 1 | タスク `0x4D8DA` | 最終進角 = clamp(`0x7AE0`+`0x7B98`+`0x7DA4`, 最大リタード `0x7AFC`, 最大進角 `@0xCE20C`) → **`0xFFFF7AA4`**（クランプは `0x4D9D0` で helper `0x2404`） |
| 2 | タスク `0x4D84E` | `0x7AA4` → 進角側のレート制限 → `0xFFFF7AA0`（OBD PID 0x0E の元）→ 気筒別補正 `@0xCE1F4..0xCE200` を加算 → **気筒別点火値 `0xFFFF7AC8/7ACC/7AD0/7AD4`** |
| 3 | `0x19B44` | 気筒番号で気筒別点火値を選び、(進角 − 9.8)×65536 を点火イベント角度として格納 |
| — | タスク `0x4DD58` | `0xFFFF7AAC/7AB0` は**トルクモデル（点火効率）専用**。点火そのものには使われない |

### 仕組み

- `0x4D9D0` のクランプ呼び出しが使うリテラル `@0x4DA98`（=`0x2404`、読むのは `0x4D9C8` だけ）を空きROMのケーブ `0xDE200` に差し替える。
- ケーブは発動条件がすべて成立していれば値からリタード量を引き、純正クランプ `0x2404` へ末尾ジャンプする。
- リタードはクランプ前に入るので、**純正の最大リタード（`@0xCE210..`、約 −10〜−14°）で下限が制限される**。下流（`0x7AA0`・気筒別・トルクモデル）はすべてリタード後の値を使う。
- 特殊モード（`0xFFFF7A94` bit7/bit6、固定点火時期など）の経路はこのクランプを通らないので影響しない。

### 発動条件（すべて成立でリタード）

| 条件 | RAM | 型 | しきい値の番地 | 既定値 |
|---|---|---|---|---|
| クラッチ踏込 | `0xFFFF6FCC` | byte（非0=踏込） | — | — |
| APP > しきい値 | `0xFFFF56C8` | float [%]（APP1/APP2合成後の最終値、0〜100） | `@0xDE260` | 80 % |
| RPM > しきい値 | `0xFFFF6D5C` | float [rpm]（PID 0x0C の元） | `@0xDE264` | 7000 rpm |
| 車速 > 下限 | `0xFFFF6D04` | float [km/h]（PID 0x0D の元） | `@0xDE268` | 10 km/h |
| リタード量 | — | — | `@0xDE26C` | 20 ° |

- 走行中はクラッチを踏んでも純正のスロットルカットは入らない（CPP clear=10000rpm）ので、**スロットルは開いたまま**。
- RPMしきい値はリタードによる“ソフトリミッタ”として働く。抑えきれない分は純正の燃料カット（MT 7500rpm）が受け止める。
- 車速下限で停車中（ローンチ側）と分けている。停車中は純正の `@0x0C53BC` スロットルカットがそのまま効く。

### エディタでの操作（v1.30〜）

1. エディタで書き込み先ECUの現在のROMを開く。
2. ツールバーの **［点火リタード］** を押す → 確認ダイアログで「はい」。メモリ上のROMにパッチが当たる（まだ保存されない）。
3. 左ツリーの **『パッチ - フラットシフト（点火リタード）』** に4項目（アクセル開度しきい値 / 回転しきい値 / 車速下限 / リタード量）が出るので、必要なら値を変える。範囲外の値は受け付けない。
4. ［名前を付けて保存］（チェックサムは自動補正）→ 予備/ベンチECUへ［ECU書き込み］。

- 既にパッチが当たっているROMを開いた場合は、最初から4項目が表示される（ボタンを押しても二重には当たらない）。
- ドラフト1のように同じ空き領域を使う別パッチが入っているROMには適用できない（エラー表示）。
- 停車中スロットルカットの **車速しきい値**（`@0x0C53B8`）と **ヒステリシス**（`@0x0C53C4`）も、『リミッタ - 回転数(レブリミット)』に追加項目として表示する（純正ROMでも表示）。

### 生成（コマンドライン）

```
python tools/patch_flatshift_retard.py --base <書き込み先ECUの現在のROM> --out <出力> --retard 20 --rpm 7000 --app 80 --vss 10
```

- 範囲チェックあり（retard 0〜30°、rpm 3000〜7500、app 0〜100%、vss 0〜250km/h）。適用済みROMや未対応ROMは拒否する。
- 同梱例 `ncec_flatshift_retard_draft3.bin` = 純正 `ncec_rom_dump.bin` ＋既定値（差分110バイト、チェックサム valid）。

### 検証状況

- 逆アセンブル:設計どおり。`@0x4DA98` を読むのは `0x4D9C8` の1箇所だけ。
- エミュレータ（`ncecu/sh2emu.py`、タスク `0x4D8DA` → `0x4DD58` → `0x4D84E` を表の順に実行、1484ケース。条件の境界値グリッド＋ランダム＋発動ケース300件）:
  - 条件成立時、`0x7AA4`・`0x7AA0`・気筒別4値が「純正ROMで `0x7B98` を −20 した結果」と全件一致（最大リタードで下限制限される分も含む）。
  - 条件不成立・特殊モードでは純正と完全一致。トルクモデル側 `0x7AAC/0x7AB0` は常に純正と同一。callee-saved レジスタの破壊なし。
  - 別設定（15°/6800rpm/85%/15km/h）でも同様に全件一致。
- **未検証**:実機での挙動。
  - ライブ計測の点火時期（PID 0x0E）は `0x7AA0` から作られるので、**リタードはライブ表示にも出るはず**。ただし発動にはRPM・車速が必要なので、ベンチではクランク/車速信号の模擬が要る。
  - 最終確認はタイミングライトで。

| 版 | 注入点 | トリガ | 状態 |
|---|---|---|---|
| draft1 `ncec_flatshift_retard_draft1.bin` | `0x4D9D8`（`0x7AA4` の書込をケーブへ） | 純正フラグ `0xFFFF3827` | 注入点は正しいが、**トリガが停車中専用**、かつ**最大リタードのクランプ後に引く**ので下限を割り得る → 使わない |
| draft2（削除済み） | `@0x4DF18`（`0x4DD58` のクランプ） | 純正フラグ `0xFFFF3827` | **トルクモデル側を変えるだけで点火は変わらない**（誤った注入点）→ 破棄 |
| **draft3** `ncec_flatshift_retard_draft3.bin` | `@0x4DA98`（`0x4D8DA` の最終進角クランプ） | 自前4条件 | 現行。ベンチ検証待ち |

### 既知の制限 / 次段

- RPMしきい値にヒステリシスが無い（しきい値付近ではリタードがオン/オフを繰り返す＝ソフトリミッタ的な動き）。
- リタード量は全回転・全ギア一律。
- 解除後の進角の戻りは純正のレート制限（`0x4D84E`）に従う。
- 半クラッチでもクラッチスイッチが入っていれば発動しうる（APP・RPM・車速条件で絞っている）。
- 安全/法規:点火リタードは排気温度を上げる。触媒・排気系への影響に注意。
