# 減速時のポップ音(オーバーラン・バーブル)調整ガイド

アクセルオフ/コースト時に「パンパン」鳴らす、いわゆる **オーバーランのポップ/クラックル(バーブル)**
を、NCの純正ECUで作るための調整手順と関連テーブルのまとめ。あわせて **ツキ(踏み直しの応答)**
の詰め方も記載する。

> ⚠ **安全・法規(必読)**
> - **熱害**:排気管内で燃料を燃やす=**触媒を焼損**(NA+純正触媒は特に危険)、排気バルブ/マニの過熱。
>   頻繁・強いポップは触媒を殺す。**純正触媒・純正マフラー車での常用は非推奨**。
> - **排ガス・騒音の違法性**:公道では未燃HC増+騒音で**違法になり得る**(触媒撤去も同様)。
> - **予備/ベンチECUで**。実車投入・公道使用は自己責任。

## 前提:NCのLF-VEは自然吸気(ターボ無し)

「アンチラグ(ALS)」は本来**ターボを回し続けてラグを消す技術**で、NAのNCには回す対象が無く**成立しない**。
ここで作るのは**"音"(オーバーランのポップ)だけ**。定義にある `Spark Correction - Tip-In Anti Lug`
は "Anti **Lug**"(低回転での**もたつき防止**)で、Anti-Lag(アンチラグ)とは別物。

## 仕組み(なぜ鳴るか)

ポップ=**排気行程/排気管側で燃料が燃える**こと。必要条件は2つ:

1. **オーバーラン中に燃料が残っている**(通常は DFCO=減速燃料カットで切られる)。
2. **点火が大きく遅角**している(燃焼が遅れて排気側へずれる)。

→ この2つを減速時に作ると鳴る。RPMで鳴らす/鳴らさないを分けたい場合は、**①の燃料の残り方をRPMで制御**する。

## レシピ（エディタの A〜D に対応）

| | 名前 | DFCO | 鳴る回転 | 遅角 | ツキ（踏み直し） |
|---|---|---|---|---|---|
| **A** | DFCO無効（全回転バーブル） | 無効 | 全回転 | 深い（〜22°） | 純正のまま |
| **B** | RPMゲート ★おすすめ | **有効** | **有効回転数より上だけ** | 20° | 純正のまま |
| **C** | RPMゲート＋ツキ重視（v2.71 新設） | **有効** | **有効回転数より上だけ** | 浅い（12°） | 速い |
| **D** | ツキ重視・DFCO無効（v2.70 までの C） | 無効 | 全回転 | 浅い（12°） | 速い |

### A. 基本バーブル(全回転で鳴らす=一番簡単)
1. **DFCO 無効化**:`@0x45976` → **9**(常時燃料)。
2. **減速点火を遅角**:`@0xD23E0` の頭打ちを **~20〜24°** へ(例 `[0,0,10,16,20,22,22,22,22]`)。
- 欠点:全コーストで鳴る(低回転でも鳴る)、燃費悪化、踏み直しの"穴"が深い。

### B. RPMゲート(有効回転数より上だけ鳴らす)★おすすめ
1. **DFCO は有効のまま**:`@0x45976` = **36610**(回転数で制御するため)。
2. **`@0xCC774`(RPM×ギア)**で燃料の残り方を分ける(全ギア行に同じ値):
   `[0.05, 0.05, 0.05, 0.0005, 0.0005]` = 回転軸の1〜3点目は **全カット(無音)**、4〜5点目は **燃料を残す(ポップ)**。
3. **有効回転数**は、この表の**回転軸 `@0xCC748`(5点)** を動かして決める(下の「アンチラグ有効回転数」)。
4. **減速点火遅角**:`@0xD23E0` を **~20°**(燃料の無い低回転では鳴らないので、遅角は残してOK)。
- 持続コースト(非Timer-Active)は別条件(`@0xCC694/698`)なので、**長く引っ張った低回転側まで完全無音にしたい**ときは、そこも上げて全カットする。

### C. RPMゲート＋ツキ重視(DFCO有効のまま)
B と同じ回転ゲート(DFCO 有効・有効回転数より上だけ)に、D の「ツキ重視」を組み合わせたもの。
1. B の 1〜3(DFCO 有効＋カット率の表＋回転軸)。
2. **減速遅角を浅く**:`@0xD23E0` 頭打ち **~12°**(復帰の"穴"を浅く)。
3. **点火復帰を速く**:`@0xD2428` → `[0.5,0.8,1.2,1.6,…]`、`@0xD2470` → `[0.6,0.9,1.2,1.6,…]`。
4. **燃料復帰を速く**:`@0xCC6A8/AC` を **0.0031 → 0.02**。
- 有効回転数より下では普通に燃料カットが効く(エンジンブレーキ・燃費は純正どおり)。ポップは B より控えめ、踏み直しは鋭い。

### D. ツキ重視・DFCO無効(v2.70 までの C)
1. **減速遅角を浅く**:`@0xD23E0` 頭打ちを **~12°** へ。
2. **点火復帰を速く**:`@0xD2428` 序盤を上げる(例 `[0.5,0.8,1.2,1.6,…]`)、`@0xD2470` も同様。
3. **燃料復帰を速く**:`@0xCC6A8/AC` を **0.003 → 0.02** 程度へ。
4. **DFCO無効**(常時燃料)。燃料復帰待ちが無いのでツキに有利だが、全回転で燃料が残る。
- **ポップとツキは相反**。両立は「遅角15〜16°+復帰は速いまま」あたりで妥協点を探す。

## アンチラグ有効回転数（B・C）

減速燃料カット率の表 `@0xCC774` は、**回転軸 `@0xCC748`(5点)を補間して**引かれる。そこで回転軸のブレークポイントを
動かすと、ゲートを**100rpm 刻みで任意の回転数**に置ける(設定範囲 **1500〜6000rpm**)。

- 回転軸 = `[x0, x1, 有効回転数, 有効回転数+1000, x4]`、値 = `[カット, カット, カット, 残す, 残す]`。
- **有効回転数以下は無音**(通常の燃料カット)。超えると効き始め、**+1000rpm で完全に有効**。
- **既定 3000rpm** のとき回転軸は `[1000,2000,3000,4000,5000]` = **純正の軸そのまま**(v2.70 までの B と同一バイト)。
- 回転軸 `@0xCC748` はこの表専用(ROM 内の参照は表記述子 `@0x93E00` の1箇所だけ)なので、他のマップには影響しない。

ECU 自身の表引きルーチン(`0x20DC`)をエミュレータで実行して確認した値(3速、カット率):

| 回転 | 2000 | 3000 | 3500 | 4000 | 4500 | 5000 | 5500 | 6000 | 7000 |
|---|---|---|---|---|---|---|---|---|---|
| 純正 | 0.007 | 0.010 | 0.020 | 0.030 | 0.040 | 0.050 | 0.050 | 0.050 | 0.050 |
| B・有効回転数 3000(既定) | 0.05 | 0.05 | 0.0253 | 0.0005 | 0.0005 | 0.0005 | 0.0005 | 0.0005 | 0.0005 |
| B・有効回転数 2000 | 0.05 | 0.0005 | 0.0005 | 0.0005 | 0.0005 | 0.0005 | 0.0005 | 0.0005 | 0.0005 |
| C・有効回転数 4500 | 0.05 | 0.05 | 0.05 | 0.05 | 0.05 | 0.0253 | 0.0005 | 0.0005 | 0.0005 |
| B・有効回転数 6000 | 0.05 | 0.05 | 0.05 | 0.05 | 0.05 | 0.05 | 0.05 | 0.05 | 0.0005 |

(0.05 = すぐ全カット＝無音 / 0.0005 = 燃料が残る＝ポップ。**実車では未確認**＝机上とエミュレータでの確認。)

## エディタの［アンチラグ］（設定 → パッチ適用）

上記 A〜D を、エディタの **設定 → パッチ適用 → アンチラグ** から適用できます（`ncecu/antilag.py`）。
- ダイアログで **A / B ★おすすめ / C / D** を選択。**B・C は「アンチラグ有効回転数 [rpm]」を入力**(1500〜6000、100刻み、既定3000)。
- 適用後、**変更した map データを一覧（リザルト）で表示**します（DFCO・回転軸・減速燃料カット率・減速点火遅角・点火/燃料の復帰など、各項目を before→after で）。
- メモリ上のROMだけ変更（保存するまでファイルは不変、保存時にチェックサム自動補正）。細かな値は適用後にツリーの該当マップで微調整できます。
- 変更してよい番地以外が1バイトでも変わったら適用を中止します(パッチ結果の自己検査)。
- **v2.70 までの「C」は「D」になりました。** 以前 C を使っていた場合は D を選ぶと同じ結果になります。

## 作動RPM域

- **下限 ≈ 約1,000〜1,500rpm**:`Estimated Idle Speed Add/Limiter`(Stage1≈1,250〜1,531 / Stage2(ブレーキ)=1,600)。
  これ以下はアイドル保護で燃料復帰=カット/ポップは止まる。
- **上限 = レブ燃料カット(このROM 7,500rpm / 純正7,000)**。
- 体感の中心は **~1,500〜4,000rpm** のコースト域。
- ※減速点火遅角(`@0xD23E0`)のX軸は RPM ではない(0〜16 の9点。定義上の軸名は `LOAD_DELTA_7C00`)。
  RPMで鳴り分けるのは**燃料側(`@0xCC774` とその回転軸 `@0xCC748`)**で行う。

## 確認方法(実機)

- **Live + AFR**:有効時=コーストでO2が無噴射/リーンへ。ポップ域=燃料が残りAFRが目標付近を維持。
- **点火時期(PID 0x0E)**:コーストで大きく遅角しているか。
- ポップは**エンジン始動+実コースト**でのみ発生(ベンチ停止では音は出ない)。
- 編集→保存(チェックサム自動補正)→ `ECU書き込み`(予備ECU)。

## 元に戻す

- 純正のROM（`rom_data/` の吸い出し原本）を開き直して書けば、減速は純正へ戻ります。
- 一部だけ戻すときは、リザルトに出た before の値を、ツリーの該当マップへ入れ直します（回転軸 `@0xCC748` の純正値は `[1000,2000,3000,4000,5000]`）。

## 注意:エディタの表示精度

`@0xCC774` の `0.0005` など**非常に小さい値**は、定義の表示書式(例 `%.3f`)だと丸めて表示されることがある
(旧版は `0.0005`→`0.001` と表示)。本ツールは小さい値を自動で高精度表示するよう修正済み。
**格納・フラッシュされる値は入力どおり**で、表示だけの問題だった(最新版で解消)。
