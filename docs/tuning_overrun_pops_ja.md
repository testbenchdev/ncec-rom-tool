# 減速時のポップ音(オーバーラン・バーブル)調整ガイド

アクセルオフ/コースト時に「パンパン」鳴らす、いわゆる **オーバーランのポップ/クラックル(バーブル)**
を、NCの純正ECUで作るための調整手順と関連テーブルのまとめ。あわせて **ツキ(踏み直しの応答)**
の詰め方も記載する。

> ⚠ **安全・法規(必読)**
> - **熱害**:排気管内で燃料を燃やす=**触媒を焼損**(NA+純正触媒は特に危険)、排気バルブ/マニの過熱。
>   頻繁・強いポップは触媒を殺す。**純正触媒・純正マフラー車での常用は非推奨**。
> - **排ガス・騒音の違法性**:公道では未燃HC増+騒音で**違法になり得る**(触媒撤去も同様)。
> - **予備/ベンチECUで**。実車投入・公道使用は自己責任。

## 前提:NCのLF-VEは自然吸気(ターボ無し)

「アンチラグ(ALS)」は本来**ターボを回し続けてラグを消す技術**で、NAのNCには回す対象が無く**成立しない**。
ここで作るのは**"音"(オーバーランのポップ)だけ**。定義にある `Spark Correction - Tip-In Anti Lug`
は "Anti **Lug**"(低回転での**もたつき防止**)で、Anti-Lag(アンチラグ)とは別物。

## 仕組み(なぜ鳴るか)

ポップ=**排気行程/排気管側で燃料が燃える**こと。必要条件は2つ:

1. **オーバーラン中に燃料が残っている**(通常は DFCO=減速燃料カットで切られる)。
2. **点火が大きく遅角**している(燃焼が遅れて排気側へずれる)。

→ この2つを減速時に作ると鳴る。RPMで鳴らす/鳴らさないを分けたい場合は、**①の燃料の残り方をRPMで制御**する。

## 関連テーブルと番地(この個体 CALID LFG7EG)

| 役割 | 場所 | 備考 |
|---|---|---|

| 〃(非RPM・他条件) | `@0xCC694`(Brake On)=0.007 / `@0xCC698`(Brake Off)=0.015 等 | 「Not Idle Trans」= 持続コースト条件。RPM軸なし |
| 全カットしきい値 | `@0xCC690` = 0.6 | 乗数がこれを割ると全カット |
| **減速点火 遅角(Base Retard\|Not Idle)** | `@0xD23E0`(1×9, X=コースト経過**時間**) | 値=遅角量°。**大=よく鳴る**。頭打ち値が効く |
| 減速点火 復帰レート | `@0xD2428` / `@0xD2470`(1×9) | **大=素早く通常進角へ戻る=ツキ良**(序盤の小さい値を上げる) |
| 減速燃料 復帰エンリッチ率 | `@0xCC6A8`(Brake On) / `@0xCC6AC`(Brake Off) | **大=踏み直しで燃料が速く戻る=息つき防止** |
| 燃料復帰 作動RPM(下限) | `Decel Fuel Restore Idle Thresholds` `@0xC48xx`(Estimated Idle Speed Add/Limiter) | これ以下はアイドル保護で燃料復帰=カット/ポップ停止 |

## レシピ

### A. 基本バーブル(全回転で鳴らす=一番簡単)
1. **DFCO 無効化**:`@0x45976` → **9**(常時燃料)。
2. **減速点火を遅角**:`@0xD23E0` の頭打ちを **~20〜24°** へ(例 `[0,0,10,16,20,22,22,22,22]`)。
- 欠点:全コーストで鳴る(低回転でも鳴る)、燃費悪化、踏み直しの"穴"が深い。

### B. RPMゲート(例:3000rpm超だけ鳴らす)★おすすめ
1. **DFCO 再有効化**:`@0x45976` → **36610**(RPMで制御するため)。
2. **`@0xCC774`(RPM×ギア)**で燃料の残り方を分ける(全ギア行に適用):
   - RPM **≤しきい値(例3000)の列** = **0.05 程度**(しっかり全カット=**無音**)。
   - RPM **>しきい値の列(4000,5000)** = **0.0005 程度(≈0)**(燃料残す=**ポップ**)。
3. **減速点火遅角**:`@0xD23E0` を **~20°**(燃料の無い低回転では鳴らないので、遅角は残してOK)。
- 境界は列の値/中間で調整。持続コースト(非Timer-Active)は別条件(`@0xCC694/698`)なので、
  **長く引っ張った低回転側まで完全無音にしたい**ときは、そこも上げて全カットする。

### C. ツキ重視(踏み直しを鋭く)
1. **減速遅角を浅く**:`@0xD23E0` 頭打ちを **~12°** へ(復帰の"穴"を浅く)。
2. **点火復帰を速く**:`@0xD2428` 序盤を上げる(例 `[0.5,0.8,1.2,1.6,…]`)、`@0xD2470` も同様。
3. **燃料復帰を速く**:`@0xCC6A8/AC` を **0.003 → 0.02** 程度へ。
4. DFCO無効(常時燃料)はツキに有利(燃料復帰待ちが無い)。
- **ポップとツキは相反**。両立は「遅角15〜16°+復帰は速いまま」あたりで妥協点を探す。

## エディタの［アンチラグ］ボタン（v2.30〜）

上記レシピ A/B/C を、エディタのツールバー **［アンチラグ］** からワンクリックで適用できます（`ncecu/antilag.py`）。
- ダイアログで **A（DFCO無効）/ B（RPMゲート）★おすすめ / C（ツキ重視）** を選択。
- 適用後、**変更した map データを一覧（リザルト）で表示**します（DFCO・減速燃料カット率・減速点火遅角・点火/燃料の復帰など、各項目を before→after で）。
- メモリ上のROMだけ変更（保存するまでファイルは不変、保存時にチェックサム自動補正）。細かな値は適用後にツリーの該当マップで微調整できます。
- 既定値は本ガイドのレシピに準拠（B の RPMゲートは 3000rpm 境界）。実例 `ncec_immo_off_na_anti.bin` は B+C 相当。

## 作動RPM域

- **下限 ≈ 約1,000〜1,500rpm**:`Estimated Idle Speed Add/Limiter`(Stage1≈1,250〜1,531 / Stage2(ブレーキ)=1,600)。
  これ以下はアイドル保護で燃料復帰=カット/ポップは止まる。
- **上限 = レブ燃料カット(このROM 7,500rpm / 純正7,000)**。
- 体感の中心は **~1,500〜4,000rpm** のコースト域。
- ※減速点火遅角(`@0xD23E0`)のX軸は**コースト経過時間(0〜16秒)**で、RPM直接ではない。
  RPMで鳴り分けるのは**燃料側(`@0xCC774`)**で行う。

## 実例:`ncec_immo_off_na_anti.bin`(同梱)

イモビ無効 + **3000rpm超だけポップ + ツキ重視**の設定例。

| 項目 | 値 |
|---|---|
| イモビ `@0x8F61E` | 9(無効) |
| DFCO `@0x45976` | 36610(有効=RPM制御のため) |
| Enleanment `@0xCC774`(全ギア) | `[0.05, 0.05, 0.05, 0.0005, 0.0005]`(1000/2000/3000=カット, 4000/5000=残す) |

| 点火復帰 `@0xD2428` | `[0.5,0.8,1.2,1.6,1.6,1.6,1.6,1.6,1.6]` |
| 燃料復帰 `@0xCC6A8/AC` | 0.02 |

## 確認方法(実機)

- **Live + AFR**:有効時=コーストでO2が無噴射/リーンへ。ポップ域=燃料が残りAFRが目標付近を維持。
- **点火時期(PID 0x0E)**:コーストで大きく遅角しているか。
- ポップは**エンジン始動+実コースト**でのみ発生(ベンチ停止では音は出ない)。
- 編集→保存(チェックサム自動補正)→ `ECU書き込み`(予備ECU)。

## 元に戻す

- `ncec_immo_off.bin`(イモビのみ無効・減速は純正)を書けば減速は純正へ。
- 完全純正は `ncec_rom_dump.bin`。

## 注意:エディタの表示精度

`@0xCC774` の `0.0005` など**非常に小さい値**は、定義の表示書式(例 `%.3f`)だと丸めて表示されることがある
(旧版は `0.0005`→`0.001` と表示)。本ツールは小さい値を自動で高精度表示するよう修正済み。
**格納・フラッシュされる値は入力どおり**で、表示だけの問題だった(最新版で解消)。
