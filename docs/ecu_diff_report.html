ECU 差分レポート — ベンチ vs 実車

ベンチ(基準) ncec_rom_dump.bin → 実車 ecu_readout_original.bin ・生成 2026-10-09

吸出しの健全性
両ROMとも 1,048,576 B（1MB）。コード/ブート/文字列領域は完全一致、差分はキャリブ領域+末尾チェックサムのみ → 読み出しは正常。両者とも同一CAL ID LFG7EG0W.Z02なので既存定義がそのまま適用可。
結論：実車 ≠ ベンチ基準（実車の方がノーマル寄り）
1521バイト（0.145%, 36クラスタ）が相違。変更箇所は「現車合わせの定番項目」に集中（レブ・速度リミッタ・ファン・VE・点火）。向き（レブ7000・180km/hリミッタあり・ファン早め）から、ベンチ予備ECUは過去にチューンショップ等で現車合わせ済み、実車は工場JDMノーマルに近いと推定されます。
重要：これまでのノート値はベンチ個体のもの。実車へ書くものは必ず ecu_readout_original.bin を基準に。

3. 未定義の相違領域 = トルクモデル（RE完了）

RE完了：この領域（0xC16D8–0xC41FC）はスパーク効率トルクモデル
ECU内部の記述子配列(0x9365C)から寸法・軸を確定し、消費コード(0x3C6D4)の逆アセンブルで数式を特定: T = T_MBT(回転,負荷) − k(回転,負荷)·(スパーク偏差)² + 温度補正。12面=17×13(回転×負荷, map01-11)+13×8(回転×温度, map12)。役割: 最適トルクT_MBT(03/10/11, N·m)・MBT点火(02/07/08/09, °)・スパーク損失係数k(01/04/05/06, 無次元)・温度補正(12)。単位N·mはDIのBMEPトルク要求との演算一致(負側 -43.8≈-44.2 N·m)で確定。差分は最適トルク3面(03/10/11)のみ=トルク出力だけを現車合わせ。12面はエディタに定義済(カテゴリ WIP - Torque Model Bank (RE))。詳細は map_analysis_JA.html。

4. 影響を受けるノート（再基準化対象）

  • リミッタ - 回転数（レブリミット）
  • リミッタ - 車速（スピードリミッタ）
  • エンジン負荷 - Scaling（VE）
  • 点火ベース - 高燃料要求 Low-Det
  • 点火ベース上限 - 低燃料要求
  • ファン制御（水温しきい値）

これらのカテゴリの「値」はベンチ個体のものです。実車基準の解析に切替える場合はこれらを実車値で再ダンプします。
