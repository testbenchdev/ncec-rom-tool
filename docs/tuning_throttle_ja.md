# スロットル1:1化（ワイヤースロットル風ハイレスポンス）

電子スロットル（DBW）のペダルマップ（アクセル開度APP → スロットル開度）を **1:1（スロットル% = アクセル%）** に立てて、ワイヤースロットル風の即・比例した付きにするガイドと生成ツール。

> ⚠ 走行フィールに直結。**予備/ベンチECUで確認**し、元ROMは必ず保管。スロットルは物理上100%（約85°）以上は開かない＝**変わるのは到達の速さ・付きで、全開時の空気量（＝ピークパワー）は増えない**。公道・法規・駆動系への配慮は自己責任。

## なぜDBWはワイヤーより鈍いか

1. ペダルマップがわざと**進角的（下が緩い）**＝小さい踏み込みでは小さくしか開かない（ドライバビリティ・排ガス・トラクションのため）。
2. アクセルとスロットルの間に**トルクモデル**が挟まる。

純正1速の例：アクセル30%で**スロットル21%**しか開かない。ワイヤーは1:1（30%→30%）。これを対角線に立てるのが1:1化。

## 対象マップ（2026-10-20 ブロック探索で確定）

ペダルマップ（APP% 18点 × RPM 10点、720B）が**制御**と**安全監視（Data Integrity）**で**完全同一に二重化**されています。**片方だけ変えると監視が不一致を検出してフェイルセーフ（スロットルを絞る）**になるため、必ず両方を同じ値にします。

| ギア | 制御 | 監視 |
|---|---|---|
| 1速 | `@0xC7EE4` | `@0xF7C90` |
| 2速 | `@0xC81B4` | `@0xF7F60` |
| 3速 | `@0xC8484` | `@0xF8230` |
| 4〜6速 | `@0xC8754` | `@0xF8500` |
| ニュートラル | `@0xC8A24` | `@0xF87D0` |

指令上限（`Throttle Duty Commanded - Maximum`、9点）も二重化：**制御 `@0xC55FC` / 監視 `@0xF7C24`**。

## 仕組み

- 各セル `new = 純正×(1−blend) + APP軸値×blend`（0〜100でクランプ）。**blend=1.0 で完全1:1**（全ギア共通、`[0,2.3,5,7.5,10,15,20,25,30,35,40,45,50,60,70,80,90,100]`）。
- 1:1 は純正の上限ライン上（中〜高ペダルで余裕ゼロ）に乗るため、**監視の誤フォルト防止に上限を `cap_margin`[%]（既定10）引き上げ**ます。
- WIP/ブレーキ/フォルト時などの特殊ペダルマップは安全側なので変更しません。

## 生成（コマンドライン）

```
python tools/patch_throttle_1to1.py --base ncec_immo_off.bin --out ncec_immo_off_throttle1to1.bin
```

- オプション：`--blend 0.7`（純正寄せ）、`--cap-margin 10`（上限引き上げ[%]）、`--keep-idle 2`（アイドル直上の列を純正のまま残す）。
- 範囲チェック・APP軸チェック・制御==監視チェック付き。非対応/破損ROMは拒否。
- 本体ロジックは `ncecu/dbw_throttle.py`。

### エディタの［電スロチューニング］ボタン（v2.30〜）

コマンドラインを使わず、エディタのツールバー **［電スロチューニング］** からも適用できます。
- ダイアログで **blend（0=純正〜1=完全1:1）/ 指令上限の引き上げ[%] / アイドル直上で残す列数** を指定。
- 適用後、**変更した map データ（全ギアのペダルマップ 制御/監視＋指令上限）をリザルト表示**します。
- メモリ上のROMだけ変更（保存するまでファイルは不変、保存時にチェックサム自動補正）。生成結果は内部で自己検証（制御==監視・値・上限内・チェックサム）。

同梱例 **`ncec_immo_off_throttle1to1.bin`** = 実車運用中の `ncec_immo_off.bin` に 1:1（blend=1.0 / cap_margin=10）を適用（差分2416バイト、チェックサム valid、**イモビ無効設定は保持**）。

### 1:1化後の各ギア row0（低回転）

いずれも `[0, 2.3, 5, 7.5, 10, 15, 20, 25, 30, 35, 40, 45, 50, 60, 70, 80, 90, 100]`（＝APP軸、完全1:1）。制御=監視を全ギアで確認済み。

## 検証状況

- 全ギアで制御==監視・1:1値・チェックサム正常・冪等（再適用で不変）・イモビ設定保持を確認。複数ベースROMでも成立。
- **実走は未検証**。ライブ計測で **アクセル（PID 0x49/0x4A）とスロットル（PID 0x11）** を並べ、踏み量にスロットルが即・比例して付くかを確認してください（PID間引きでTPS/APPを速く）。

## 注意

- **2速の低回転50%上限は1:1化で外れます**（純正はトラクション保護で2速低速を50%に抑えている）。2速の低速で開けやすく＝ホイールスピンしやすくなります。残したい場合は 2速だけ `--blend` を下げるか、エディタで2速（制御`@0xC81B4`＋監視`@0xF7F60`）を手当て。
- 立てすぎは**ギクシャク・発進やタイトコーナーでの扱いにくさ**を招きます。穏やかにしたいときは `--blend 0.6〜0.8`。
- スロットルは100%以上開きません。**ピークパワーは不変**、変わるのは付き（レスポンス）。
- 予備/ベンチECUで、吸い出しバックアップ必須。書き込み中は電源を切らない。
